# 数智伴学 — 易班技术创新大赛作品
班级：26电子1班 邓茗图
项目简介：数智伴学，大学高数启发式助手，面向工科新生。内置高数知识库，不直接给出答案，采用启发式提问引导学生自主推导，点明易错点，并提供同类习题巩固，助力工科大一学生自主学习高等数学。

## 运行方法
1. 安装依赖库
打开命令行，执行：
pip install -r requirements.txt

2. 启动后端服务
python test_api.py

3. 打开网页
浏览器访问 http://127.0.0.1:5000

## 文件说明
test_api.py：后端接口程序
index.html：前端交互网页
